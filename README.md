# amstudio — Projekte

Sieben eigenständige Website-Konzepte für Südtiroler Handwerksbetriebe, jedes mit eigener
Designsprache statt Template. Übersicht: `portfolio.html`.

- `index.html` — Elektro Schmid (Schaltplan-Motiv, dunkel/elektrisch)
- `starkstrom/` — Starkstrom, Jürgen Larcher, Brixen (Swiss-Poster-Stil, Starkstrom-Blau)
- `schaiter/` — Electro Schaiter, Sterzing (warm, Kupferdraht-Linie)
- `maler-wieser/` — Maler Wieser, Kortsch (Farbflächen, interaktive Musterkarte)
- `reichegger/` — Elektro Reichegger, Loxone-Partner (Blueprint, Tag-im-Haus-Zeitleiste)
- `baukei/` — Baukei, Lana, EIB/KNX (interaktiver Vierfach-Taster-Demo)
- `riegler/` — Elektro Riegler, Deutschnofen/Bozen, seit 1977 (Quiet Luxury, Referenzen, Zeitlinie)

Lokal ansehen: `python3 -m http.server` im Projektordner, dann `/portfolio.html` öffnen.
